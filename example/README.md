# Demo deck

Shows every layout of `slidev-theme-swiss-print` with neutral content: a fake speaker (Alex Martin), a fake talk
("Queues are not magic") and reserved `.example` domains. The end-to-end tests in `../tests/e2e` run against this deck,
so slide order matters: append new slides at the end and update the `SLIDES` maps in the tests.

Run it with `npm run dev` from the repo root.
